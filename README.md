# PRACIMA® — Landing page

Página de vendas da loja **PRACIMA®** (Salvador, Bahia).

- Slogan: Vista-se de Positividade
- Instagram: [@usepracima](https://instagram.com/usepracima)
- Loja física: Rua da Paz, n° 1, Graça, Salvador — BA, 40150-140

## Como ver

Abra `index.html` no navegador ou publique no GitHub Pages (Settings → Pages → Deploy from branch `main` / root).

A pasta `img/` com as fotos está no ZIP do projeto. Suba ela na raiz do repo para as imagens aparecerem.
